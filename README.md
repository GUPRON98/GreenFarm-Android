# Green Farm (Android Port)

Porting **Green Farm** (`GloftGRFA`, J2ME 640x480) menjadi aplikasi Android native (`com.gameloft.greenfarm`) dengan tampilan fullscreen landscape dan kontrol layar sentuh.

## Download APK
Unduh **`GreenFarm.apk`** (`2.1 MB`) dari halaman [Releases](https://github.com/GUPRON98/GreenFarm-Android/releases/latest) atau langsung dari root repository ini.

## Build dari Source
```bash
./build_apk.sh
```
Output APK: `GreenFarm.apk` (dan `/sdcard/ai/GreenFarm.apk`).
